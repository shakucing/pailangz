## Commands

```sh
pnpm typecheck
pnpm test
pnpm test:integration
pnpm build
# After building; creates an isolated temporary database and web server:
pnpm test:web
```

Both `test:integration` and `test:web` create and remove isolated temporary databases. By default they use PGlite. Set `TEST_PG_BIN_DIR` to an installed native PostgreSQL `bin` directory for real concurrent connections; each runner starts a separate temporary cluster on a free port and never uses an existing database. The HTTP runner also starts its own loopback web server and requires an existing production build.
